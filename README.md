# Beside

It's all for the people, but the source code isn't open source.

## Project documents

- [Game Design Document](docs/GAME-DESIGN.md) — game vision, gameplay loop, world, combat, dungeons, items, UI/UX, milestones and acceptance criteria.
- [Art Bible](ART.md) — visual direction, proportions, palette, performance budgets and asset rules.
- [Quality Upgrade Roadmap](QUALITY_ROADMAP.md) — prioritized quality and engineering work.
- [Asset Sources and Licenses](ASSETS.md) — provenance, license evidence and pinned asset sources.
- [GLB Asset Audit](ASSET_AUDIT.md) — model topology and texture budget measurements.
- [Android Profiling](docs/ANDROID-PROFILING.md) — on-device performance capture notes.
- [Runtime State](STATE.md) — implementation stage history.

The design document distinguishes implemented systems from proposed work. A feature must be verified in the runtime and tested before it is described as complete.
